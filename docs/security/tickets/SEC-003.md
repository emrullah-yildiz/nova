## Gap
When a user chats with the AI copilot, Nova silently sends both the user's
message AND a token-bounded snapshot of their live project graph (node types,
controls, wiring) to a third-party AI provider — the shared free-tier proxy
(Groq, then Gemini) or, for BYOK, directly to the user's chosen provider. There
is **no in-product disclosure** that this leaves Nova for a third party, and **no
opt-out** other than not using the feature. The only surface mentioning it is a
single line buried in the AI knowledge-base primer.

## Why it matters (user-rights impact)
Designers may treat project graphs as confidential client work. Transmitting that
content to an external AI vendor without a clear, contextual notice undermines the
right to be informed (GDPR Art. 13) and the user's ability to make an informed
choice. The shared free tier in particular routes data through Nova's own keys to
Groq/Gemini, which the user did not choose.

## Evidence
- Prompt + graph context assembled and sent: `src/ai/gpt-client.js` (PROXY_URL
  `/api/proxy/chat`, BYOK `apiUrl` to Groq/Gemini), `src/ai/graph-context.js`
  (`buildGraphContext` injected into the system prompt).
- Proxy forwards to external providers: `worker/index.mjs` `/api/proxy/chat`.
- Only disclosure found: `src/ai/knowledge-base.js:75` ("It uses your API key
  (BYOK) or a shared free model") — not a data-handling notice and not shown at
  the point of sending.

## Recommended action / acceptance criteria
- CODE: add a clear, one-time (persisted) disclosure before the first AI send —
  "Your message and a summary of your current graph are sent to <provider> to
  generate a response" — with a link to the privacy policy and a way to decline /
  use BYOK only. Show the active provider in the chat UI.
- POLICY: ensure the privacy policy (SEC-001) and sub-processor list (SEC-002)
  cover AI providers.
- Acceptance: a new user cannot send graph data to a third-party AI provider
  without having seen the disclosure at least once; the choice is persisted.

## Progress (2026-06-04)
AI data-flow disclosure drafted in `docs/legal/data-handling.md` §3 and
`privacy-policy.md` §3. Confirmed with the maintainer: **no free tier** — the assistant
is **BYOK-only**, and BYOK requests go **browser → provider directly** (Nova's servers
are not in the path; we only store the encrypted key). So the disclosure states the
prompt + graph context go to the provider *the user* configured, under the user's own
arrangement; no model training; no prompt logging. REMAINING (mixed): decide whether an
in-app notice is required before first AI use (legal), then implement that UI (code).
Status: in-progress.
